# 🇮🇳 Agniveer GD Eligibility Checker (Python)

A simple, interactive command-line tool built in Python to check the preliminary physical eligibility of male candidates applying for the **Indian Army Agniveer General Duty (GD)** category.

---

## 🚀 Features Included
- **Age Validation:** Strictly checks if the candidate is between **17.5 and 21 years old**.
- **Height Check:** Verifies against the standard plains requirement of **170 cm**.
- **Weight Range:** Ensures the weight is within the healthy bracket of **52 kg to 63.6 kg**.
- **Chest Parameter:** Checks for the minimum chest size of **77 cm**.
- **Marital Status:** Validates that only **unmarried** candidates are allowed.
- **Physical Fitness Test (PFT) Tracking:** 
  - Converts and checks running time against the **345-second (5 min 45s) limit**.
  - Ensures a minimum of **6 pull-ups (beams)** are completed.
  - Checks the mandatory **Zig-Zag balance beam** pass criteria.

---

## 🛠️ How to Run the Program

1. Make sure you have **Python 3** installed on your system.
2. Download or clone this repository.
3. Open your terminal or VS Code inside the project folder.
4. Run the script using the following command:
   ```bash
   python Agniveer.py
   ```
